## Description

This model implements a sequential agent-based simulation of dyadic formation. Agents are processed one at a time from an ordered collection, where each agent, when activated, determines its next action and communicates through a mediator. Interaction requests are passed between agents in a message-driven manner, and each agent makes decisions based on its internal rule engine.

The simulation does not use parallelism; instead, it follows a deterministic, step-by-step execution where agents act individually in sequence.
